# 01 - SOLID Principles

5 Prinsip desain kode agar mudah dikelola (Maintainable).

1.  **S - Single Responsibility Principle**: Satu fungsi/class hanya boleh punya SATU alasan untuk berubah (satu tugas).
2.  **O - Open/Closed Principle**: Terbuka untuk ekstensi, tertutup untuk modifikasi. (Pakai plugin/inheritance, jangan ubah kode inti).
3.  **L - Liskov Substitution Principle**: Sub-class harus bisa menggantikan Parent-class tanpa error.
4.  **I - Interface Segregation Principle**: Klien tidak boleh dipaksa bergantung pada interface yang tidak mereka pakai. (Di JS: Jangan bikin object raksasa "God Object").
5.  **D - Dependency Inversion Principle**: Bergantung pada abstraksi, bukan implementasi konkret. (Dependency Injection).
