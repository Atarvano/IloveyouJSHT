# Tugas Akhir 01: Web Interaktif (To-Do List)

Selamat! Kamu sudah sampai di tahap proyek. Tugasmu adalah membuat aplikasi To-Do List sederhana.

## Fitur yang Harus Ada:
1.  **Input Teks**: Untuk menulis nama tugas.
2.  **Tombol Tambah**: Saat diklik, tugas masuk ke daftar di bawahnya.
3.  **Daftar Tugas**: Menampilkan tugas-tugas yang sudah ditambahkan.
4.  **Fitur Hapus**: Setiap tugas punya tombol "Hapus" (atau klik tugasnya untuk menghapus).

## Petunjuk:
- Buka `index.html` dan `script.js` di folder ini.
- HTML dan CSS dasar sudah disiapkan.
- Kamu hanya perlu melengkapi logika di `script.js`.

Selamat mengerjakan!
