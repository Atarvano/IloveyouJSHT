# 🧩 Rekomendasi Extension untuk JavaScript Master

Karena kamu pakai editor berbasis VS Code (seperti Google Antigravity/IDX), ini adalah "Starter Pack" extension wajib biar coding makin ngebut dan pro.

## 1. Wajib Punya (Essentials)

- **ESLint**: Polisi kode. Dia bakal marahin kamu kalau ada kode yang potensi error atau tidak rapi. Sangat penting untuk materi _Clean Code_.
- **Prettier - Code formatter**: Tukang rapi-rapi otomatis. Simpan file, langsung rapi. Ga perlu pusing spasi berantakan.
- **Error Lens**: Fitur dewa! Error coding langsung muncul di samping barisnya (warna merah). Ga perlu hover-hover mouse lagi.

## 2. Produktivitas (Productivity)

- **Auto Rename Tag**: Kalau ubah tag `<div>` jadi `<section>`, tag penutupnya `</div>` otomatis berubah jadi `</section>`. Hemat waktu banget. **(Catatan: Fitur ini tidak tersedia di Google Antigravity/IDX.)**
- **Path Intellisense**: Biar ga salah ketik nama file saat import/require. Dia bakal kasih saran path otomatis. **(Catatan: Fitur ini tidak tersedia di Google Antigravity/IDX.)**
- **Code Spell Checker**: Mencegah typo bahasa Inggris (misal `funtion` harusnya `function`). Typo variabel itu musuh utama programmer!

## 3. Visual (Biar Ganteng)

- **Material Icon Theme**: Ikon folder dan file jadi cantik dan gampang dibedakan (ikon JS, HTML, CSS beda-beda).
- **Indent-Rainbow**: Mewarnai indentasi (tab) biar kelihatan jelas blok kodenya (mana kurung buka, mana kurung tutup).

## 4. Advanced (Untuk Nanti)

- **GitLens**: Kalau sudah main Git, ini wajib. Bisa liat siapa yang nulis kode baris itu dan kapan.
- **Turbo Console Log**: Tekan shortcut, langsung bikin `console.log` otomatis dengan nama variabelnya. Debugging jadi kilat.

## 5. Alternatif (Jika Tidak Tersedia)

Jika beberapa ekstensi di atas tidak tersedia atau tidak berfungsi optimal di lingkungan editor Anda (misalnya Google Antigravity/IDX), berikut beberapa saran cadangan:

- **Untuk Auto Rename Tag**: Manfaatkan fitur _multi-cursor_ (Alt + Klik atau Ctrl+D) untuk mengubah tag pembuka dan penutup secara bersamaan, atau gunakan fitur _Rename Symbol_ bawaan editor (F2) jika memungkinkan untuk komponen atau elemen yang lebih kompleks.
- **Untuk Path Intellisense**: Biasakan menggunakan _autocomplete_ bawaan editor saat mengetik path, atau gunakan fitur _Go to Definition_ (F12) pada import/require untuk memastikan path yang benar.

---

**Cara Install:**
Cari ikon kotak-kotak (Extensions) di sidebar kiri, ketik nama extension di atas, lalu klik **Install**.
