# Modul 00: Persiapan Belajar

## Apa itu JavaScript?
JavaScript (JS) adalah bahasa pemrograman yang membuat website menjadi "hidup". Jika HTML adalah tulang, dan CSS adalah kulit/baju, maka JavaScript adalah otot dan otak yang menggerakkan website.

## Persiapan Tools
1.  **Code Editor**: Kamu sudah pakai (VS Code atau Project IDX).
2.  **Browser**: Google Chrome (untuk inspect element/console).
3.  **Node.js** (Opsional tapi disarankan): Untuk menjalankan JS di terminal tanpa browser.

## Cara Menjalankan Kode JavaScript
Ada 2 cara utama:

### 1. Di Browser (Console)
- Buka Chrome.
- Klik kanan -> Inspect -> pilih tab **Console**.
- Ketik `alert("Halo Dunia")` dan tekan Enter.

### 2. Di HTML
Buat file HTML dan masukkan tag `<script>`:
```html
<script>
  console.log("Halo dari file HTML!");
</script>
```

### 3. Di Terminal (pakai Node.js)
- Buat file `coba.js`.
- Isi dengan `console.log("Tes terminal");`.
- Buka terminal, ketik `node coba.js`.
