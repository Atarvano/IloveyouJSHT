# Tugas Akhir 03: Build Your Own Framework (KyarJS)

Ini adalah ujian terakhir untuk gelar "Sepuh". Kamu akan membuat library JavaScript sendiri.

## Spesifikasi "KyarJS"
Library kamu harus punya fitur:
1.  **Reactivity**: Fungsi `reactive()` untuk membuat object reaktif.
2.  **Component System**: Fungsi `mount()` untuk merender komponen ke DOM.
3.  **State Management**: Store sederhana yang bisa dishare antar komponen.

## Tugas
1.  Buat file `kyar.js` (Library kamu).
2.  Buat file `app.js` (Aplikasi yang pakai library kamu).
3.  Bikin aplikasi "Counter" sederhana menggunakan `KyarJS`.
    *   Ada tombol "+" dan "-".
    *   Angka berubah otomatis di layar tanpa `document.getElementById` manual di `app.js` (harus dihandle library).
