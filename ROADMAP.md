# Peta Jalan Belajar JavaScript (Zero to Framework Creator)

Ini adalah kurikulum **ULTIMATE**. Tujuannya bukan cuma bikin kamu bisa pakai JS, tapi paham sampai ke akar-akarnya (V8 Engine, Memory) dan bisa bikin Framework sendiri.

## Tahap 1: The Bedrock (Fondasi Kokoh)

1.  **00-Persiapan**: Setup environment professional.
2.  **01-Dasar-JavaScript**:
    - _Deep Dive_: Type Coercion, Scope Chain, Hoisting, Strict Mode.
3.  **02-Logika-Percabangan-Perulangan**:
    - _Deep Dive_: Short-Circuit (`&&`, `||`, `??`), Bitwise Operators, Error Handling Patterns.
4.  **03-Fungsi-Modular**:
    - _Deep Dive_: Higher-Order Functions, Currying, Composition, IIFE, Recursion.

## Tahap 2: Data & Browser Internals (Pendalaman)

5.  **04-Struktur-Data**:
    - _Deep Dive_: Iterators, Generators, WeakMap/WeakSet, Big O Notation.
6.  **05-DOM-Manipulasi**:
    - _Deep Dive_: Event Propagation (Capturing/Bubbling), Shadow DOM, Custom Elements, Virtual DOM Concept.
7.  **06-JavaScript-Modern-ES6**:
    - _Deep Dive_: Proxy & Reflect (Metaprogramming), Symbols, Classes (OOP).

## Tahap 3: Advanced & Under the Hood (Sepuh Level)

8.  **07-Asynchronous**:
    - _Deep Dive_: Event Loop Phases, Microtasks vs Macrotasks, Web Workers.
9.  **08-Engine-Internals**:
    - _Deep Dive_: V8 Architecture (Ignition & TurboFan), AST, Memory Management (Garbage Collection).

## Tahap 4: Architecture & Engineering (God Tier)

10. **09-Design-Patterns**: SOLID Principles, Singleton, Factory, Observer, Strategy.
11. **10-Performance-Security**: Memory Leaks, Optimization, XSS, CSRF.
12. **11-Build-Your-Own-Framework**: Reactivity System, Virtual DOM Implementation, Routing.
13. **12-State-Management**: Bikin Redux Clone, Immutability, Observables.
14. **13-Tooling-Bundling**: AST Transformers, Babel Plugin, Bundler concepts.

## Tahap 5: Computer Science (LeetCode Ready)

15. **14-DSA-Algoritma**: Big O, Data Structures (Stack, Queue, Tree, Graph), Algorithms (Sorting, Searching), Dynamic Programming.

## Tahap 6: Final Projects (Pembuktian)

- **Tugas-Akhir-01**: Web Interaktif (To-Do List) - _Refactor dengan Clean Code_.
- **Tugas-Akhir-02**: Web Kompleks (Movie App) - _Refactor dengan Architecture Pattern_.
- **Tugas-Akhir-03**: **Mini-Framework (KyarJS)** - Bikin library sendiri & pakai untuk bikin app.
