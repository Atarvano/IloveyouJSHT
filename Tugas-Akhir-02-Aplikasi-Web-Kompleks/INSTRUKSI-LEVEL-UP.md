# Tugas Akhir 02: Movie App (Architected)

## Level Up Requirements:
1.  **Module Pattern**: Pecah kodemu menjadi beberapa file:
    *   `api.js`: Khusus handle fetch ke OMDb.
    *   `ui.js`: Khusus handle manipulasi DOM (render card).
    *   `app.js`: Menggabungkan keduanya.
    *   Gunakan `<script type="module">` di HTML.
2.  **Error Handling**: Tampilkan pesan error yang cantik di UI jika internet mati atau film tidak ketemu.
3.  **Async/Await**: Wajib pakai ini, dilarang pakai `.then()` biasa.

Buktikan kodemu rapi dan modular!
